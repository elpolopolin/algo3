El subgrafo inducido por _W_ es el grafo _G_ [ _W_ ] dado por 

_V_ ( _G_ [ _W_ ]) = _W_ 

y 

_E_ ( _G_ [ _W_ ]) = _{uv ∈ E_ ( _G_ ) : _u, v ∈ W }._ 


![](../imagenes/teo2-intro-grafos.pdf-0042-14.png)
